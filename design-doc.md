# Design Document

## Project Description

This project is a personal homepage built using vanilla HTML5, CSS3, and ES6 JavaScript modules.

The website introduces who I am, my technical interests, projects, and goals as a computer science student. The homepage also includes a projects page and an AI-generated page.

The website was designed as a front-end only static website without using external frameworks or component libraries.

# User Personas

## Persona 1 — CS Student Recruiter

A recruiter looking for student portfolios quickly wants to understand my technical background, projects, and interests.

Goals:
View projects quickly
Understand technical skills
Navigate the website easily


## Persona 2 — Fellow Student

A fellow student interested in web development projects wants to explore the homepage and see examples of front-end work.

Goals:
Browse projects
Explore design and layout
Learn from the structure of the website


# User Stories

As a recruiter, I want to quickly view project information so that I can evaluate technical experience efficiently.

As a visitor, I want to switch between light and dark mode so that I can browse the website more comfortably.

As a student, I want to navigate between multiple pages so that I can explore projects and AI-generated content easily.
